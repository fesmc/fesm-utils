fesm_clock

Run clock, cadences and output/restart schedules

Overview

fesm_clock is one run clock for a coupled model: integer ticks inside, real(dp) years at every interface, a declared calendar. Model time is n ticks (integer(int64)) with N ticks per year (ticks_per_year, default 36000), so every common step (1, 0.5, 0.1, 0.01, 0.001, 1/12, 1/360, 1/32 yr) is a whole number of ticks. Years are never accumulated: every time the clock returns is n/N, evaluated once, so t1 of one interval is bit-identical to t0 of the next.

  • clock_t: the run (time_init, time_end, dtt), the views of model time, the calendar and year length, restart state.
  • cadence_t: “every dt yr” on the absolute grid phase + k*dt (counted from 0, not from time_init), or every step. Due once per grid time; the component is told the interval [t0, t1].
  • schedule_t: output or restart times (none | const | times | file, keys as in timeout), on the step grid, with a cursor.

Every year value (from a namelist or an argument) is converted once to ticks and must be a whole number of ticks; every grid relation is checked at init, so a run that starts can never miss or round a time:

Check Where Rule
Year values every init, clock_to_ticks whole number of ticks (4-ulp test), |n| < 2^53
Step grid clock_init dtt > 0, time_end > time_init, time_end = time_init + k*dtt, time_ref whole years
Cadence grid on the step grid cadence_init dt a multiple of dtt, phase on the step grid
Schedule times on the step grid schedule_init times outside [time_init, time_end] are dropped first
Restart times on every cadence grid clock_start with an active restart schedule: every restart time and time_end; an empty intersection of the cadence grids stops

The design note docs/dev/clock-design.md gives the rationale (choice of N, precision, chunk alignment).

Views and calendar

method clock_time clock_time_rel (forcing time) clock_time_cal
rel n/N = time time_rel + time_ref
cal n/N time − time_ref = time
const n/N frozen at time_const time_rel + time_ref

clock_time_elapsed counts from the experiment start, which survives chunk continuations. Paleo runs use rel with negative times (−21000 = 21 ka BP).

The calendar (360_day, 365_day alias noleap, none) places the model-time year fraction in days and months; gregorian and julian are rejected, as their year length varies. The year length year (360d, 365d, julian, gregorian, tropical, the sec_year_* of phys_constants) converts rates and is independent of the calendar. Neither has a default: both are required.

Public API

All times in and out are real(dp) years; ticks appear only in clock_to_ticks, clock_to_years, is_multiple_of_all and restart files. init, start, clock_to_ticks, the restart reads and the calendar queries take an optional stat (set to 1 instead of stopping, see fesm_log).

Name Purpose
clock_init(clk, filename, group [, defaults_file, stat]) Keys time_init, time_end, dtt, calendar, year (required), method (rel), time_ref (1950), ticks_per_year (36000), and for const exactly one of time_const, time_const_cal. A key may come from defaults_file (same group).

clock_restart_write(clk, file), clock_restart_read(clk, file [, stat]) Clock state; read sets clk%continued.

An output schedule includes time_init (const; times/file if listed) and always time_end; a restart schedule excludes time_init. const lists the absolute multiples of dt. After clock_finish, every output schedule is due once; a restart schedule only if clock_restart_allowed, otherwise the skipped bundle is logged with the offending cadence.

Example

The driver loop of a coupled model (namelist groups ctrl, tm_2D, tm_rst):

use fesm_clock

call clock_init(clk, path_par, "ctrl")
call cadence_init(c_ice, clk, "ice", every_step=.true.)
call cadence_init(c_geo, clk, "geo", dt=10.0_dp)
call schedule_init(s_2D,  clk, "out_2D",  path_par, "tm_2D")
call schedule_init(s_rst, clk, "restart", path_par, "tm_rst", restart=.true.)
if (restart /= "None") call run_restore(restart, dom, clk, c_ice, c_geo)
call clock_start(clk)                                   ! validate, log the table

do
    if (schedule_due(s_2D, clk))  call write_2D(dom, clock_time(clk))
    if (schedule_due(s_rst, clk)) call run_restart_write(dom, clk, c_ice, c_geo)
    if (clock_finished(clk)) exit

    call clock_advance(clk)
    call forcing_update(frc, clock_time_rel(clk))

    if (cadence_due(c_geo, clk)) then
        call cadence_interval(c_geo, clk, t0, t1)
        call geo_update(dom%geo, t0, t1)                ! integrates [t0, t1]
        call cadence_mark(c_geo, clk)
    end if
    if (cadence_due(c_ice, clk)) then
        call ice_update(dom%ice, clock_time(clk))
        call cadence_mark(c_ice, clk)
    end if
end do

run_restore calls clock_restart_read and then cadence_restart_read for each cadence; run_restart_write the two writes. With

&ctrl
    method    = "rel"
    time_init = -21000
    time_end  = 0
    dtt       = 5
    calendar  = "365_day"
    year      = "tropical"
/
&tm_2D
    method = "const"
    dt     = 1000
/
&tm_rst
    method = "const"
    dt     = 5000
/

Chunks and restarts

Because the grids are absolute, a chain of chunks (time_init = previous time_end) fires every cadence and output at the times of one long run, whatever dtt each chunk uses. clock_restart_read detects a continuation when the bundle time equals time_init (continued = .true., the elapsed origin is kept, cadences restore their last mark) and a branch otherwise (elapsed origin and last marks reset to time_init). The bundle holds clock_ticks_per_year, clock_n, clock_n_origin, clock_dtt and cadence_<name>_{n_last,dt,phase} as dp scalars (exact for |n| < 2^53; ncio has no int64) and the attribute clock_method; a bundle written at another N is converted exactly or rejected.

fesm_clock is independent of timestepping (tstep_class) and timeout, which are unchanged.
